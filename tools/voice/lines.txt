# The companion's voice clips: `name: text`, one per line. Run: uv run python make_clips.py lines.txt

# Moments play automatically: battle_cry, victory, timber, door, death, level_up, greeting, respawn.

# battle_cry__<enemy> clips are for that enemy only (battle_cry__troll2...): when a fight starts against one, those come first.
# Any other name is a clip the agent can choose to go with something it says.
#
